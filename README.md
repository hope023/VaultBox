# VaultBox 文件保险箱

Windows 桌面小工具：**加密隐藏文件夹** + 快速隐藏。Tauri 2 + Rust + 原生 HTML/JS。

## 功能

### 加密保险箱

把任意文件夹变成保险箱：

- **上锁**：文件夹内所有文件、文件名、目录结构全部加密（AES-256-GCM），只剩 `.vaultbox/data/` 下的一堆乱码数据 —— 拷走整个文件夹也看不到任何内容
- **解锁**：输密码后文件恢复原名原样，资源管理器 / Excel / WPS 直接用
- **增量**：上锁时未改动过的文件复用已有密文，秒级上锁；改动过的才重新加密
- **自动上锁**：解锁状态下无操作 10 分钟自动上锁（密钥仅在解锁期间驻留内存）
- **崩溃安全**：加解锁全程 journal 记录，异常中断（断电/杀进程）后下次解锁自动恢复
- **不卡界面**：重操作全部在工作线程执行（async + spawn_blocking），实时进度推送（转圈 + N/M 计数）；800 文件上锁约 9 秒，期间界面完全流畅
- **防暴力尝试**：连续输错 5 次密码锁定 30 秒

### 快速隐藏

切换 Windows「隐藏」属性（递归）。**防误看，不防懂行的人** —— 资源管理器开启「显示隐藏的项目」后依然可见。需要真正保护请用保险箱。

## 使用

```bash
npm run tauri dev        # 开发运行
npm run tauri build      # 打包
```

直接使用：运行 `src-tauri/target/release/vaultbox.exe`（免安装单文件）。

1. 选一个空文件夹（或确认非空文件夹）→ 设密码 → 初始化
2. 解锁后：导入文件/文件夹，或直接把文件丢进文件夹
3. 用完点「立即上锁」（或等自动上锁）

## 技术与安全边界

- 密码经 **Argon2id**（64 MiB / 3 轮）派生 256 位密钥；盐与验证块存于 `meta.json`
- 每文件、每 512 KiB 分块独立随机 nonce 的 **AES-256-GCM** 流式加解密（大文件内存占用恒定）
- 密文布局：`[u32 块长][nonce][GCM 密文]` × N；索引整体加密存于 `index.enc`
- 密钥仅在解锁会话期间驻留内存（`zeroize` 清理），密码永不落盘
- 删除文件采用「覆写一次 + 删除」；不做多轮擦除（NTFS/SSD 上无意义）

**诚实边界**：本工具防「他人拷贝/翻看你的文件」，不防取证级对手（内存取证、键盘记录器等）。密码丢失**无法找回**，无后门。

## 项目结构

```
src/                 前端（原生 HTML/CSS/JS，无框架）
src-tauri/src/
  crypto.rs          Argon2id + AES-GCM（含单测）
  store.rs           磁盘格式：meta/index/journal + 原子写 + 覆写删除
  vault.rs           生命周期：创建/解锁/上锁/导入/崩溃恢复（含集成测试）
  hide.rs            Windows 隐藏属性切换（Win32，含单测）
  commands.rs        Tauri 命令门面：会话密钥 + 错误锁定 + 自动上锁
  lib.rs             入口 + 自动上锁 watcher
```

测试：`cd src-tauri && cargo test`（23 个：加解密往返、防篡改、全生命周期、崩溃恢复、GC、空目录保留、大文件流式、路径逃逸防护）。
